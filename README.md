# Calendrier ESI PWA

Fichiers prêts pour GitHub Pages.

1. Uploade tout le contenu de ce dossier à la racine du dépôt.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Ouvre ensuite l'URL GitHub Pages dans Chrome Android et choisis Installer l'application / Ajouter à l'écran d'accueil.
